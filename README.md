# Cycle — дневник менструального цикла

Веб-приложение для телефона (PWA). Работает без интернета и без сервера. Все записи хранятся только в браузере телефона.

## Что умеет
- Отмечать начало и конец месячных: одной кнопкой «сегодня» или любой датой.
- Прогноз следующих месячных (среднее по последним 6 циклам) с диапазоном «самый короткий – самый длинный».
- Фазы цикла, оценка овуляции и фертильного окна (6 дней по Wilcox 1995). **Это не метод контрацепции.**
- Ежедневные отметки: выделения, настроение, энергия, 14 симптомов, заметка.
- Боль: сила по шкале 0–10, где болит, какая боль, лекарство и помогло ли, описание своими словами с подсказками.
- «Дневник боли» во вкладке «Статистика» и кнопка «Для врача», которая копирует дневник текстом.
- Статистика: средний цикл, длительность, разброс, график относительно нормы FIGO. Показывает, какие симптомы повторяются перед месячными.
- Предупреждения по критериям FIGO и NHS: короткие или длинные циклы, большой разброс, долгие месячные, задержка, кровь между месячными, повторяющаяся сильная боль.
- 17 подсказок и справочник «Как устроен цикл» (фазы, фертильное окно, овуляция) со ссылками на источники (`tips.js`).
- Нажатие на пункт легенды календаря или на название фазы открывает объяснение.
- Копия данных в файл и восстановление из файла.

## Запуск
Любой статический хостинг, например GitHub Pages. Локально:
```
cd cycle-tracker && python3 -m http.server 8000
```
На телефоне откройте адрес в браузере и выберите «На экран Домой» (Safari) или «Установить приложение» (Chrome).

## Пороговые значения и источники
| Параметр | Значение | Источник |
|---|---|---|
| Норма длины цикла | 24–38 дней | FIGO, Munro et al. 2018 — https://doi.org/10.1002/ijgo.12666 |
| Длительность месячных | ≤ 8 дней | там же |
| Разброс циклов | ≤ 7–9 дней | там же |
| «Показаться врачу» при разбросе | ≥ 20 дней | nidirect (NHS) — https://www.nidirect.gov.uk/conditions/irregular-periods |
| Фертильное окно | 5 дней до овуляции + день овуляции | Wilcox 1995, NEJM — https://www.nejm.org/doi/full/10.1056/NEJM199512073332301 |
| Лютеиновая фаза для оценки овуляции | 14 дней (в реальности в среднем 12,4, с большим разбросом) | Bull 2019 — https://pmc.ncbi.nlm.nih.gov/articles/PMC6710244/ |
| Нет месячных > 3 циклов при отрицательном тесте | к врачу | nidirect — https://www.nidirect.gov.uk/conditions/stopped-or-missed-periods |
